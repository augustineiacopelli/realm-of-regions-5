# Realm-of-Regions 5: Adventure Calls

A turn-based adventure game designed by Simon. Travel through 15 regions, fight their enemies for gold and XP, buy swords, food and pets, and beat each region's dragon to unlock the next. Beat the Snowy Plain Dragon to unlock a DLC with 3 more regions.

**Play it:** https://augustineiacopelli.github.io/realm-of-regions-5/

## About
- One self-contained `index.html`, no build step and no dependencies.
- Saves automatically in the browser. Use the Save code button on the map screen to move progress to another device or browser.
- Not part of the AppADay portfolio.
- Easy to change numbers (starting HP, XP growth, pet strength) live in the `CONFIG` block near the top of the script.
